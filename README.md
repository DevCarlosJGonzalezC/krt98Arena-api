# ⚽ krt98 Arena - API ⚽

API para gestionar canchas sinteticas en Medellin.
Permite ver las canchas disponibles y consultar el detalle de cada una por si ID.

Proyecto de aprendizaje - Dia 3

## Tecnologias

- Node.js
- Express

## Como correrlo

npm install <br>
node server.js <br>

## rutas disponibles

## 🛣️ Rutas disponibles

| Método | Ruta | Qué hace |
| --- | --- | --- |
| GET | `/` | Mensaje de bienvenida |
| GET | `/canchas` | Lista todas las canchas |
| GET | `/canchas/:id` | Muestra una cancha por su ID |
